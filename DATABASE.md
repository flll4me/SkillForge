# Локальная база данных

Проект использует PostgreSQL. Конфигурация контейнера находится в `compose.yaml`, пример настроек — в `.env.example`.

## Запуск

1. Установи и запусти Docker Desktop.
2. В терминале из корня проекта скопируй `.env.example` в `.env`.
3. Запусти базу командой `docker compose up -d database`.
4. Проверь состояние командой `docker compose ps`.

Строка подключения для Node.js backend хранится в `DATABASE_URL`. Compose публикует PostgreSQL только на локальном компьютере (`127.0.0.1`). Данные сохраняются в Docker volume `postgres_data` между перезапусками контейнера.

Значения из `.env.example` предназначены только для локальной разработки. Не используй их для публичного или production-сервера.
