# Статистика администратора

Панель: `/admin`. API: `GET /api/admin/statistics?days=7|30|90`.
Доступ проверяется по текущей роли и статусу пользователя в базе.
Интерфейс обновляет данные каждые 60 секунд, пока вкладка видима.

## Показатели

- Общее число аккаунтов и активных вопросов/навыков — за всё время.
- Новые аккаунты, начатые интервью, завершение, результаты и популярные темы — за выбранные календарные дни UTC, включая сегодняшний день.
- Длительность интервью — время между началом и завершением, включая перерывы. В расчёт входят завершённые интервью, начатые в периоде.
- Время на сайте — среднее активное время по измеренным посещениям, начатым в периоде. Пустые посещения исключаются. При отсутствии измерений API возвращает `null`, интерфейс показывает «—».
- Активные пользователи — уникальные пользователи измеренных посещений за период. Сейчас на сайте — пользователи с ненулевым измеренным временем и последним сигналом не старше 90 секунд. Это оценка присутствия, а не точное число подключений.

## Сбор времени

Миграция `011_activity_sessions.sql` добавляет таблицу посещений. Выполнить `npm run migrate:api`, затем перезапустить backend. Docker запускает миграции автоматически при старте нового образа.

Вошедшие обычные пользователи отправляют накопленное время в `POST /api/users/me/activity` каждые 15 секунд. Гости и администраторы не отслеживаются. Первая отправка регистрирует посещение, следующие добавляют время. Учитывается видимая вкладка в фокусе, в течение двух минут после взаимодействия. Фоновые вкладки, сон компьютера и длительное бездействие исключаются. Перерыв больше 30 минут, перезагрузка страницы или повторный вход начинают новое посещение. Короткие посещения до первого измерения не входят в среднее.

Сервер связывает посещение с пользователем из токена, проверяет активный аккаунт, не позволяет менять чужие посещения и ограничивает прирост временем между сигналами (максимум 20 секунд за сигнал). Накопленные значения защищают от повторного начисления при повторной отправке. Сетевые потери могут уменьшать измеренное время; это приблизительная аналитика, не биллинг.

Содержимое страниц, нажатые клавиши, IP и адреса переходов в этой таблице не сохраняются. Историческое время до подключения сбора восстановить нельзя. История интервью и регистраций доступна сразу.

## Проверка учёта времени на PostgreSQL

Тест `backend/test/activity-database.test.ts` по умолчанию пропускается. Он проверяет повторные и устаревшие сигналы, ограничение длительности и защиту чужого посещения. Тестовые аккаунты и посещения создаются внутри транзакции, которая откатывается после проверки.

Запуск в PowerShell из папки `backend` после миграции:

```powershell
$env:RUN_DATABASE_TESTS = '1'
npm test -- --configLoader native --pool=threads test/activity-database.test.ts
Remove-Item Env:RUN_DATABASE_TESTS
```
